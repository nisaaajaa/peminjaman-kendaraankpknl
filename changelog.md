# LOG PENGEMBANGAN (CHANGELOG)
*(File ini berfungsi sebagai buku sejarah proyek. Tambahkan entri baru DI BAGIAN PALING ATAS)*

**Format Entri:**
`[YYYY-MM-DD HH:MM WIB] [TAG] nama-file.js/html: Deskripsi ringkas namun teknis.`

**Tag yang Digunakan:**
- `[INIT]` : Inisialisasi awal proyek, setup database, atau kerangka dasar.
- `[FEATURE]` : Penambahan fitur atau fungsionalitas logika baru.
- `[BUGFIX]` : Perbaikan kode yang bermasalah, error, atau anomali UI.
- `[REFACTOR]` : Perbaikan struktur kode (under-the-hood) tanpa mengubah fitur.
